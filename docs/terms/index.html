利用規約

本規約は、インボイス請求書メーカー（以下「当サイト」）が提供する各種ツールおよびコンテンツの利用条件を定めるものです。 当サイトをご利用になった時点で、本規約に同意いただいたものとみなします。

1. サービスの内容

当サイトは、請求書・見積書・納品書・領収書の作成ツール、および消費税等の計算ツールを無料で提供します。 会員登録は不要で、利用回数の制限もありません。

2. 利用にあたっての注意

  • 当サイトが提供する書式は、一般的な様式に基づく参考例です。取引先の要求する様式や、個別の業界慣行に必ずしも適合するとは限りません。
  • 作成した書類の内容の正確性については、利用者ご自身でご確認ください。
  • 入力データは利用者の端末内にのみ保存されます。ブラウザのデータ消去や端末の変更により失われる場合がありますので、重要な書類は「保存」機能でファイルとして書き出すか、PDFとして保存してください。

3. 禁止事項

  • 法令または公序良俗に反する目的での利用
  • 虚偽の内容の書類を作成し、第三者を欺く目的での利用
  • 当サイトのシステムに過度の負荷をかける行為
  • 当サイトのコンテンツを無断で複製し、同種のサービスとして再配布する行為

4. 免責事項

当サイトの情報およびツールは、一般的な情報提供を目的としたものであり、税務・法務に関する助言ではありません。 当サイトの利用により生じたいかなる損害についても、運営者は責任を負いません。 税務上の判断については、国税庁の公式情報を確認するか、税理士等の専門家にご相談ください。

また、当サイトは予告なくサービス内容の変更・中断・終了を行う場合があります。

5. 準拠法

本規約の解釈および適用は、日本法に準拠します。
