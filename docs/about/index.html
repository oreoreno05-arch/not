このサイトについて

インボイス請求書メーカーは、インボイス制度に対応した請求書を、誰でも無料で・登録なしで作れるようにするために作られたツールです。

作った理由

インボイス制度が始まってから、請求書に書くべきことが増えました。登録番号、税率ごとの区分、 そして「税率ごとに1回」という端数処理のルール。どれも難しい話ではありませんが、 毎月の請求業務でひとつずつ確認するのは面倒です。

既存のクラウド会計サービスは高機能ですが、月に数枚の請求書を出すだけの個人事業主にとっては オーバースペックで、アカウント登録のハードルもあります。 「今すぐ1枚だけ、正しい形式の請求書がほしい」という需要に応えるのが、このサイトの役割です。

大事にしていること

入力データを預からない

請求書には取引先の名前と金額という、事業の中核にあたる情報が入ります。 当サイトはこれらをサーバーに送信しません。計算も書類の組み立てもすべてブラウザ内で完結し、 データは利用者の端末にのみ保存されます。

制度のルールに素直に従う

端数処理を明細ごとに行う実装は、作るのは簡単ですが制度上認められていません。 当サイトでは「1つの請求書につき税率ごとに1回」というルールを実装し、 国税庁のQ&Aで示された設例と同じ結果になることをテストで検証しています。

無料で使い続けられるようにする

作成枚数の上限や、PDF保存時の課金はありません。運営費用は広告でまかなう方針です。

提供しているツール

  • 請求書メーカー（インボイス6要件のチェック付き）
  • 見積書メーカー
  • 納品書メーカー
  • 領収書メーカー
  • 消費税・源泉徴収税 計算機（経過措置シミュレーター付き）

情報の正確性について

掲載している解説記事は、国税庁が公表している情報および税制改正の内容をもとに作成しています。 ただし本サイトは税理士事務所ではなく、記事は一般的な情報提供を目的としたものです。 個別の事情による判断は、税理士等の専門家にご相談ください。

記載内容に誤りを見つけられた場合は、リポジトリの Issue からお知らせいただけると助かります。
