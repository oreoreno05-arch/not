適格請求書（インボイス）の書き方｜6つの記載事項を記載例つきで解説

公開日: 2026-07-28更新日: 2026-07-31

適格請求書には、決まった様式はありません。必要なのは6つの記載事項がもれなく書かれていることだけです。 逆に言えば、1つでも欠けると取引先が仕入税額控除を受けられなくなり、修正依頼という手間が発生します。 この記事では、6つの項目を一つずつ、実際の書き方と間違えやすいポイントとともに解説します。

適格請求書の6つの記載事項

#記載事項インボイス制度で追加された項目
1適格請求書発行事業者の氏名または名称および登録番号登録番号が追加
2取引年月日—
3取引内容（軽減税率の対象品目である旨）—
4税率ごとに区分して合計した対価の額および適用税率適用税率が追加
5税率ごとに区分した消費税額等追加
6書類の交付を受ける事業者の氏名または名称—
6項目は自動でチェックできます

当サイトの請求書メーカーでは、入力しながら6つの記載事項の充足状況がリアルタイムで表示されます。抜け漏れのまま送ってしまう事故を防げます。

項目ごとの書き方と注意点

1. 氏名または名称と登録番号

登録番号は「T」＋13桁の数字です。法人の場合は「T＋法人番号」がそのまま使われ、 個人事業主の場合は法人番号とは別に新しい番号が付番されます。屋号だけを記載する場合でも、 登録を受けた氏名または名称が特定できる必要があります。

登録番号は必ず自分のものを確認

桁の打ち間違いは頻出の不備です。国税庁 適格請求書発行事業者公表サイトで自分の番号を確認し、テンプレートに保存しておきましょう。

2. 取引年月日

請求書を作成した日ではなく、実際に商品を引き渡した日やサービスを提供した日を書きます。 1か月分をまとめて請求する場合は、「2026年7月1日〜7月31日」のように課税期間をまとめて記載することも認められています。

3. 取引内容（軽減税率の対象品目である旨）

品目やサービス名を具体的に書きます。「品代」「お品代」だけでは内容が特定できず不十分とされる可能性があります。 軽減税率（8%）の対象が含まれる場合は、その品目に「※」などの記号を付け、 欄外に「※は軽減税率対象」と注記する方法が一般的です。

4. 税率ごとに区分した対価の額と適用税率

10%対象・8%対象それぞれの合計額を分けて記載します。税抜・税込どちらの表示でも構いませんが、 合計額だけの記載では要件を満たしません。

5. 税率ごとに区分した消費税額等

税率ごとの消費税額を記載します。ここで最も重要なのが端数処理のルールです。 1円未満の端数処理は、1つの適格請求書につき税率ごとに1回しか行えません。 明細ごとに端数処理をして合計する方法は認められていません。

詳しくは 消費税の端数処理のルール で解説しています。

6. 交付を受ける事業者の氏名または名称

取引先の正式名称を書きます。「(株)」などの略称は避け、登記上の名称を使うのが無難です。 「上様」や宛名なしは原則として要件を満たしません。

記載例（レイアウト見本）

6つの記載事項を満たした請求書は、たとえば次のような構成になります。

ヘッダー「請求書」というタイトル／請求書番号／①発行者名と登録番号 T1234567890123
宛先⑥株式会社サンプル商事 御中
日付②2026年7月31日（または取引期間）
明細③Webサイト制作 / ※弁当代（※は軽減税率対象）
集計④10%対象 250,000円 / 8%対象 3,920円
⑤消費税 25,000円 / 313円

請求書メーカーの「見本データを入れる」ボタンを押すと、 この構成のサンプルがそのままプレビューに表示されます。

適格簡易請求書が使える業種

不特定多数の相手に販売する次の事業では、記載事項を簡略化した適格簡易請求書を交付できます。

  • 小売業
  • 飲食店業
  • 写真業
  • 旅行業
  • タクシー業
  • 駐車場業（不特定多数向け）
  • その他これらに準ずる事業

適格簡易請求書では宛名の記載を省略でき、「適用税率」または「税率ごとに区分した消費税額等」のどちらか一方の記載で足ります。 レシートを交付する業種はこちらを使うと実務が楽になります。 領収書メーカーでも作成できます。

よくある質問

手書きの請求書でもインボイスになりますか？

なります。適格請求書に決まった様式はありません。6つの記載事項がすべて記載されていれば、手書きでもExcelでも、レシートや納品書でも適格請求書として扱われます。

請求書と納品書に分けて記載してもいいですか？

問題ありません。複数の書類全体で6つの記載事項を満たしていれば、それらの書類を合わせて1つの適格請求書として扱えます。ただし、書類同士の関連性が明確である必要があります。

「上様」宛ての領収書は使えますか？

原則として使えません。適格請求書には交付を受ける事業者の氏名または名称が必要です。ただし小売業・飲食店業・タクシー業などが交付する「適格簡易請求書」では、宛名の記載を省略できます。

記載漏れがある請求書を受け取ったらどうすればいいですか？

発行者に修正した適格請求書の交付を求めてください。区分記載請求書等の時代と異なり、受け取った側が自分で追記して修正することは原則として認められていません。
